# Job hunt tracker

- `applications.csv` – every application (date, company, role, level, exp asked, location, ATS, status, link). Status `Applied` = submitted and confirmed.
- `applications-calendar.html` – GitHub-style calendar of applications per day (download and open in a browser; hover a square for the count, click for the roles).
- `companies.md` – target companies by priority, read by the job-apply-autopilot plugin.

Updated by Claude after each batch of applications.
